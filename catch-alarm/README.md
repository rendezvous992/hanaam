# 캐치알람 (local.catchalarm)

업무공간 서버와는 무관한 개인용 안드로이드 앱입니다 (Vercel 배포에서 제외: `.vercelignore`).
캐치테이블 앱 알림 / 카톡 '캐치테이블' 알림톡을 잡아 알람으로 크게 울리고, '지금 열기'로 매장 화면을 엽니다.

## 설치 (1.4)

폰 크롬에서 이 링크를 열면 APK 가 받아집니다:
https://github.com/rendezvous992/hanaam/raw/ccr-cbe2ff8b-w22bpj/catch-alarm/catch-alarm-1.4.apk

예전 캐치알람(1.3)과 서명이 달라 **기존 앱을 먼저 삭제**하고 설치해야 합니다. 키워드·매장 링크·인원·권한은 다시 설정합니다.

## 1.4 에서 바뀐 것
- 설정에 **예약 날짜·시간 지정** (달력/시계로 고름, 지난 날짜는 무시)
- 날짜 순서: ① 알림 문구에 날짜가 있으면 그 날짜 ② 없으면 지정한 날짜. 알람 온 날(오늘)은 넣지 않음
- '지금 열기' 순서: 알림 속 매장 링크 → 설정한 매장 링크(날짜 포함) → 캐치테이블 원래 알림 → 앱
  (1.3 은 캐치테이블 원래 알림을 먼저 열어서 날짜가 안 들어갔음)
- 알람 화면에 넣을 조건("📅 10월 15일 (목) 19:00 · 2명") 표시, '캐치테이블 원래 알림 열기' 버튼
- 설정 화면에 실제로 열릴 링크 미리보기

## 빌드
원래 소스가 없어 1.3 APK 를 풀어 다시 쓴 소스입니다. `./build.sh [versionCode] [versionName]`
(필요한 jar 는 build.sh 머리말 참고). 서명 키(`catchalarm.p12`)는 공개 저장소라 올리지 않았습니다 —
같은 키로 서명해야 삭제 없이 업데이트되므로 키는 따로 보관합니다.
